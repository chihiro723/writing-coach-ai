# 英作文添削 AI

OpenAI GPT-4 を活用した英検対応の英作文添削システム

🌐 **[デモサイト](https://writing-coach-ai.vercel.app/)**

## プロジェクト概要

実用英語技能検定（英検）の英作文対策に特化した Web アプリケーション。AI による即座のフィードバックで、いつでもどこでも効率的な英語学習が可能です。

## 主要機能

- 文法・スペル・表現チェック
- 100 点満点での詳細採点
- 論理性評価
- 模範解答生成
- AI 問題生成エンジン

## セットアップ

```bash
# リポジトリクローン
git clone https://github.com/your-username/writing-coach-ai.git
cd writing-coach-ai

# 依存関係インストール
npm install

# 環境変数設定
echo "OPENAI_API_KEY=your_openai_api_key_here" > .env.local

# 開発サーバー起動
npm run dev
```

## 使用方法

### 1. 問題選択・生成

#### AI 生成問題のカスタマイズ設定

**📚 対応レベル**

- 英検 3 級・準 2 級・2 級・準 1 級・1 級
- 大学受験（入門・標準・上級）

**🗂️ ジャンル選択肢**

- 教育・環境・医療・法律・政治・経済
- 歴史・言語・文化・ジェンダー・科学技術
- インターネット・メディア・人口問題・自分について

**📝 単語数設定**

- 回答単語数: 10〜250 語（10 語刻み）
- 推奨設定: 80-100 語

### 2. 英作文執筆

- 指定された問題に対して英文を記述
- リアルタイムで文字数をカウント表示
- 推奨単語数の範囲内での執筆を推奨

### 3. AI 添削・評価の実行

#### 📊 評価項目（100 点満点）

| 項目               | 配点  | 評価内容                                 |
| ------------------ | ----- | ---------------------------------------- |
| **文法・スペル**   | 40 点 | 基本文法、語彙、スペリング、冠詞・前置詞 |
| **内容・論理性**   | 40 点 | 質問への回答、論理展開、具体例・根拠     |
| **構成・まとまり** | 20 点 | 序論・本論・結論、段落構成、全体の流れ   |

#### 🔍 添削機能

- **文法チェック**: 修正箇所と理由を日本語で詳細解説
- **論理性評価**: 議論の一貫性と説得力を分析
- **模範解答**: レベルに応じた理想的な解答例を自動生成

### 4. 学習・復習

- 添削結果を確認し、弱点を把握
- 模範解答と比較して表現力を向上
- 次回の執筆に活かすためのポイントを整理
